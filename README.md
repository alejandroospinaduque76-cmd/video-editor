# Video Editor Kit

Editor de video que manejas hablando con [Claude Code](https://claude.com/claude-code).
Le das el clip en bruto y te devuelve el video editado y exportado: subtítulos, cortes, color y sonido.
Sirve para reels verticales y para videos de YouTube.

## Cómo empezar

1. Descarga el repo: botón verde **Code → Download ZIP**, o `git clone`.
2. Descomprime y abre la carpeta en Claude Code (la carpeta que tiene `setup.sh` y `CLAUDE.md`).
3. Escribe: **"Instálalo en mi computador"**. Claude corre `./setup.sh`, instala lo que falta y detecta tu editor (Premiere, DaVinci Resolve, CapCut o Final Cut).
4. Prueba con un clip corto de 20 a 60 segundos.

Si prefieres leer antes de instalar, abre `START-HERE.html` en el navegador o lee `SETUP.md`.

## Requisitos

- Claude Code instalado.
- Mac (Apple Silicon o Intel), Windows o Linux.
- Unos GB libres para las herramientas que instala `setup.sh`.

Versión 1.4.
